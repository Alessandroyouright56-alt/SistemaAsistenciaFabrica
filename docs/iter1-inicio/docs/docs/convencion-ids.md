# Convención de identificadores — Tema 07

Proyecto: Sistema de Control de Asistencia
para una Fábrica de Caramelos

| Elemento | Formato | Descripción |
|---|---|---|
| Requisito | REQ-### | Funcionalidad o condición del sistema |
| Caso de uso | CU-### | Interacción para cumplir un requisito |
| Clase | CLS-Nombre | Elemento del diseño del sistema |
| Prueba | PRU-### | Comprobación de un requisito |
| Solicitud de cambio | CR-### | Petición de modificación del sistema |

## Reglas

1. Cada elemento debe tener un identificador único.
2. No reutilizar identificadores existentes.
3. Mantener los mismos IDs en todos los documentos.
4. Relacionar requisitos con casos de uso, clases y pruebas.
5. Registrar los cambios utilizando IDs CR.
