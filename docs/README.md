# Sistema de Control de Asistencia Dasyar

## 1. Descripción del proyecto

El Sistema de Control de Asistencia Dasyar busca digitalizar el registro de asistencia de los trabajadores de una fábrica de caramelos, reemplazando el registro manual en cuaderno por un proceso automatizado.

El sistema contempla la identificación mediante huella dactilar y, como alternativa, DNI + PIN. También considera el registro de fecha y hora, el control de tardanzas, la consulta de asistencias y la exportación de información a Excel.

## 2. Objetivos

- Reducir los problemas asociados al registro manual de asistencia.
- Facilitar la consulta de los registros de los trabajadores.
- Automatizar la identificación de tardanzas según los horarios y la tolerancia configurados.
- Organizar los artefactos del proyecto mediante el proceso unificado RUP y UML.

## 3. Alcance de la primera iteración

La primera iteración se centra en la visión del sistema, la planificación, la documentación inicial, la organización de los artefactos y la identificación de riesgos.
